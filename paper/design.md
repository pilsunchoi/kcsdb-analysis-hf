# 2019 일본 수출규제 event study → 학술논문 발전 설계

*본체 = 합성통제(방향 A), 확장 = 품목 이질성(방향 B). 초안 `2019_japan_export_control_hf.md`을 계량 식별틀로 재구성한다.*

---

## 0. 기여 진술 (한 문장으로 좁힌다)

> HS10 관세 미시자료에 합성통제법을 적용해, 2019년 일본 수출규제가 반도체용 불화수소 수입에 미친 인과효과를 추정하고, permutation 추론으로 유의성을 검정한다. 동일 규제에 대한 품목별 반응 이질성을 대체가능성·전용코드 유무로 설명한다.

- **국산화는 결론이 아니다.** 관세DB만으로는 확증 불가하므로, 관측사실("수요조정 후에도 남는 수입강도 하락")과 가설로만 서술한다. 국산화를 결론으로 올리려면 KOSIS 광공업동태조사 병합이 선결이며, 이는 후속 논문(방향 C)으로 분리한다.

## 1. 초안 대비 바뀌는 것 — 결함별 대응

| 초안의 결함 | 논문에서의 대응 |
|---|---|
| 인과 추정량 없음(−90%는 점추정) | 합성통제 처치효과 + DiD 회귀(계수·clustered SE) 병기 |
| 반사실이 자의적('직전12개월+수요조정') | 도너풀 기반 합성 반사실로 대체. 대조군 기타HF는 특이성이 아니라 in-space placebo로 통합 |
| 단일 event·단일 처치 → 추론 불가 | permutation(in-space placebo) 분포로 p값 산출 |
| 분모(칩수출) 측정오차 | 분모를 (a)칩수출액 (b)웨이퍼생산지수(KOSIS) (c)반도체 물량지수 3종으로 두고 강도 결과 민감도 병기 |
| wgt≈0 함정 제외 기준 불명시 | 임계값 명시 + 포함/제외 양쪽 결과 부록에 병기 |
| 국산화를 핵심 기여로 배치 | 관측사실로 격하, 가설로만 명시, 방향 C로 분리 |

## 2. 식별 전략

### 2.1 합성통제 (본체)

- **처치단위**: `2811111000`(반도체 제조용 HF) 대일 수입액(월별, log).
- **결과변수 후보**: ① 대일 수입액 ② 총수입액 ③ 수입강도(총수입/수요대리). 셋을 각각 추정해 "일본선 붕괴 vs 총수입 축소"를 분해.
- **도너풀**: 규제 미대상 화학 HS10 중, 2019.07 이전 추세가 안정적이고 일본 의존이 있던 품목. 예: 기타 무기산·기타 에칭/세정용 화학품. 도너풀 선정 기준(사전추세 안정성, 결측 없음, 규제 무관)을 명문화.
- **처치시점**: 2019m7. 사전기간 2015m1–2019m6, 사후 2019m7–2026m3.
- **추론**: in-space placebo(각 도너를 가짜 처치로) → RMSPE 비율 분포 → permutation p값. in-time placebo(2018m7 등)도 병기.

### 2.2 DiD 보조 회귀

```
log(import_ijt) = α + β·(Treated_i × Post_t) + γ_i + δ_t + ε_ijt
```
- Treated = `2811111000`, 대조 = `2811119000`(기타HF).
- 국가 j를 일본으로 한정한 2×2 DiD와, 다국가 패널 DiD 둘 다.
- SE는 품목 클러스터. event-study 계수(사전 리드·사후 래그)로 병행추세 시각화.

### 2.3 병행추세 사전검정

- 사전 리드 계수가 0과 구분되지 않음을 보인다(초안의 플라시보를 계수화).

## 3. 논문 구성 (초안 절 → 논문 절 매핑)

1. **서론** — 경제안보·수출규제 문헌, 기여 3가지(미시자료 합성통제 / 물량-가격 분해 / 품목 이질성).
2. **제도 배경** — 2019.07 규제, 3대 품목, HS10 식별. (초안 1절)
3. **자료** — KCSDB2, HS10 식별전략, 전용코드 논거, 한계(일본→제3국·국내생산 부재). (초안 1·9절)
4. **식별전략** — 합성통제 + DiD (위 2절).
5. **주결과** — 처치효과(대일/총/강도), event-study plot. (초안 2절)
6. **추론·강건성** — permutation, in-time placebo, 대조군, 물량기준, wgt 민감도. (초안 3·4절)
7. **메커니즘** — 가격 vs 물량 분해, 수입강도(분모 3종), 공급선 집중도(HHI). (초안 4·5·6절)
8. **지속성** — 일본선 회복 vs 강도 저위 고착. (초안 7절)
9. **품목 이질성(확장, 방향 B)** — HF/포토레지스트/OLED PR 궤적, 대체가능성으로 설명. (초안 8절)
10. **결론·정책** — durable 효과 = 수입강도 하락, 국산화는 가설, 필요자료.

## 6. 남은 결정 사항 (Pilsun 판단 필요)
